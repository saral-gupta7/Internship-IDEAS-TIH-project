## Project Aim

This project demonstrates core image processing and machine learning workflows for an internship assignment. It applies OpenCV transformations, builds a PyTorch image augmentation pipeline, loads image datasets with Torchvision, and evaluates clustering performance on digit data using K-Means and macro F1 score.

## Covered Tasks

- Load and process an image with OpenCV.
- Convert an image to grayscale and save the result.
- Apply image shifting, resizing, and rotation.
- Create a PyTorch/Torchvision training transform pipeline.
- Load cat/dog images using `ImageFolder`.
- Create a `DataLoader` and inspect batch tensor shapes.
- Load the sklearn digits dataset.
- Fit a K-Means clustering model.
- Evaluate clustering with macro F1 score after cluster-label mapping.

## Local Setup

Requires Python 3.12 or newer.

### Option 1: uv

This project uses `uv` as the Python environment and dependency manager.

Install dependencies:

```bash
uv sync
```

Start Jupyter locally:

```bash
uv run jupyter lab
```

### Option 2: pip

Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Start Jupyter locally:

```bash
jupyter lab
```

Open and run:

```text
09_Imagedata_Augmentation_and_Image_Classification_Spring_2026.ipynb
```

The notebook name should remain unchanged for submission.
